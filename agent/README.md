# Agent Work Records

This folder keeps project work records for agent-assisted development.

Recommended usage:

- `worklog.md`: chronological decisions, implementation notes, and verification results.
- `tasks/`: optional per-task notes when a change spans multiple files or systems.
- `tmp/`, `logs/`, `cache/`, and `artifacts/`: local runtime output. These paths are ignored by Git.

Keep records concise and evidence-based: include dates, changed surfaces, commands run, and remaining risks.

Current task docs:

- `tasks/backend-device-upload.md`: Workers `/device/upload` contract, D1 schema, and verification notes.
- `../docs/Backend-API.md`: public backend API documentation.
